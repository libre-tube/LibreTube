# Contributors

LibreTube is a community project. Everyone is welcome to contribute — code,
translations, bug reports, design and documentation.

## Maintainer

- [@brunlx](https://github.com/brunlx) — main developer and maintainer of this
  fork. Author of the media-engine hardening (SABR/DASH/HLS source selector),
  livestream fix, playback-source tests and repository maintenance.

## Upstream authors

This repository is a fork of
[LibreTube](https://github.com/libre-tube/LibreTube). All original contributors
are credited in the upstream project and, when active, in the git history of
this repository (`git shortlog -sne`).

## Become a contributor

- Open issues and PRs following the templates and our
  [Code of Conduct](CODE_OF_CONDUCT.md).
- Translate the app on
  [Weblate](https://hosted.weblate.org/projects/libretube/).
- Test builds and report real-device results.
